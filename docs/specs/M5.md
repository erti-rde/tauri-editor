# M5 — Writing essentials

### M5-1 Version history

Refs: ADR-7, UX-9 · Depends on: M1a-8, M1a-4

- AC-1 Snapshots are format-1 manuscript files at `.erti/history/<stem>/<UTC>.erti.json`.
- AC-2 Taken at most every 10 min while changing, on close and quit, and before any restore or
  destructive operation.
- AC-3 Thinning (a day of everything, then hourly for a week, daily for 3 months, weekly
  after) runs in Rust on project open. It's a pure function of timestamps, table-tested.
- AC-4 The UX-9 view: grouped by day, word delta, trigger, read-only preview, **Restore this
  version** (which snapshots first), and the size footer with "Clear older than 3 months".

### M5-2 Find & replace

Refs: UX-11 · Depends on: —

- AC-1 ⌘F opens find; ⌘⌥F adds replace; Esc closes.
- AC-2 A match count, previous/next, match case and whole word.
- AC-3 Never matches inside citation nodes; Replace all is one undo step.

### M5-3 Spellcheck

- AC-1 `spellcheck="true"` is set explicitly on the editor.
- AC-2 Checked by a person on macOS, Windows and Linux: misspellings are marked, and the
  platform's suggestions menu works. Recorded in the release matrix.

### M5-4 PDF export per platform

Refs: UX-8 · Depends on: —

- AC-1 PDF export verified by a person on each platform: pages, running heads, citations,
  bibliography, and no app chrome.
- AC-2 Wherever `window.print()` falls short (WebKitGTK is the risk), a direct **PDF…**
  writes the file via Tauri's webview print-to-file. Decided per platform and recorded.

### M5-5 DOCX export

Refs: ADR-9, UX-8 · Depends on: —

- AC-1 `export/docx.ts` is a pure function from doc to bytes, using `docx` (measured: 102 KB
  gzip), lazily loaded.
- AC-2 Headings, lists, tables, images, page setup and running heads are mapped. Note styles
  become real Word footnotes; in-text styles render as text.
- AC-3 Golden tests over `word/document.xml` and `word/footnotes.xml` for all five vendored
  styles.
- AC-4 Opened by hand in Word and LibreOffice for the release matrix.

### M5-6 Export menu

Refs: UX-8 · Depends on: M5-5

- AC-1 The toolbar's PDF and `.tex` buttons become **Export ▾**: Check attribution first… (with
  a dot when changed since the last check; hidden if M4 moves to 1.1), PDF…, Word…, LaTeX
  bundle….
- AC-2 Every export ends with a toast offering **Show in folder**.

### M5-7 Document menu

Refs: UX-9, #23 (reduced) · Depends on: M5-1, M1a-4

- AC-1 **⋯** on the active document tab: Rename…, Duplicate, History…, Delete….
- AC-2 Rename moves the history directory. Delete moves the file to the trash and keeps its
  history.

### M5-8 Font family and size in the toolbar

Refs: #103

- AC-1 A family dropdown (the manuscript typefaces from Appearance) and a size stepper, applied
  as marks, and exported to DOCX and LaTeX where representable.

### M5-9 Draggable split divider

Refs: #100

- AC-1 Drag to resize, with a 280 px minimum per pane; the ratio persists per window; the
  divider is keyboard-operable (arrow keys when focused).

### M5-10 Settings › Library

Refs: UX-10, ADR-8 · Depends on: M1a-5

- AC-1 Library location with **Move library…** (move, then reopen).
- AC-2 Last backup, **Back up now**, **Restore from a backup…** (confirm; the replaced library
  is kept) and **Open backup folder**.

**M5 Verify:** restore yesterday's snapshot in the harness; a DOCX with citations, a table, an
image and a note-style bibliography opens correctly in Word and LibreOffice; move the library
