### M0-3 A fresh install can write before any network call **(P0)**

Refs: UX-1 · Depends on: M0-2

Found 2026-09-24: `Editor.svelte` awaits `initializeCitationStore()` before `createEditor`, and
that throws when no style is stored. The only way a style gets stored is a download in Settings,
which the CSP blocked. So a fresh install can't open the editor.

- AC-1 Seven styles ship in `src-tauri/resources/csl/styles/`: APA 7, Chicago author-date,
  Chicago notes and bibliography, Harvard (Cite Them Right), IEEE, MLA 9 and Vancouver. Two
  locales ship too: en-US and en-GB. Each has its licence header intact (CC BY-SA 3.0).
- AC-2 With no stored style, the editor mounts and citations render in APA with en-GB.
  Nothing needs the network.
- AC-3 If citation setup fails for any reason, the editor still mounts. Citations show their
  raw ids with a banner: "Citations can't be formatted: {reason}. Choose a style in Settings."
- AC-4 Settings lists bundled styles first, marked "included", and they apply without a
  download.
- AC-5 A downloaded style still works as before.

Verify: app-in-browser harness (M1a-1) once it exists; until then a vitest of the citation
store with an empty settings store; screenshot of the editor on a fresh fake backend.
