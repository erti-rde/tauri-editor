# M6 — Scale and quality gates

### M6-1 The 200-paper run

Refs: TEST, plan.md §11 · Depends on: M2, M3, M4, M5

- AC-1 A script builds a corpus of ≥ 200 openly licensed PDFs (arXiv plus PMC open access),
  including ≥ 30 two-column journal layouts, pinned by manifest and hash.
- AC-2 Measured with lookups on and off and committed: ingest time, failures by cause, metadata
  rate, index build time, peak RSS.
- AC-3 E2E journeys 1–5 pass against it.

### M6-2 Input limits

Refs: SEC-4 · Depends on: M6-1

- AC-1 Limits are set from the measurements, with headroom, and documented in
  `docs/security.md`: PDF size, `.bib` size and entries, manuscript size, sidecar size.

### M6-3 pdf.js hardening

Refs: SEC-5

- AC-1 `isEvalSupported: false` on every `getDocument`, asserted by a test.
- AC-2 A written decision on upgrading pdfjs-dist 4.9 → current. If upgraded, the golden
  extraction and metadata-health tests guard it.

### M6-4 Network capture

Refs: criterion 8

- AC-1 A release build, run through consent-declined and consent-granted journeys, behind a
  logging proxy.
- AC-2 Every host contacted is in the README list, and declined means zero connections. The
  capture summary is committed.

### M6-5 Accessibility and palettes

- AC-1 Keyboard-only traversal of every new surface (UX-1 to UX-12), recorded as a checklist.
- AC-2 The contrast test covers the new tokens. Every palette is screenshotted on each new
  surface from the harness.

### M6-6 (moved)

Moved to **M1a-12**. Building all of 1.0 without a log would mean debugging blind.

### M6-7 Threat model re-run

Refs: SEC-10

- AC-1 `docs/security.md` is updated against the finished surface. Every High is closed or
  explicitly accepted by the maintainer.

### M6-8 Design-system sweep

Refs: ADR-10 · Depends on: M1c-6

- AC-1 Every surface not migrated by earlier items (reader toolbar and sidebars, Outline,
  Explorer, TabBar, citation suggestion, bubble menu, link and table popovers) is moved onto
  primitives.
- AC-2 `design-system-baseline.json` is empty, or each remaining entry has a one-line
  justification in the file.
- AC-3 Catalogue and palette screenshots of the migrated surfaces are attached to the PR.
