# M3 — Writing companion

### M3-1 Notes and passages follow the paragraph

Refs: UX-5 · Depends on: M2-1

- AC-1 The Notes panel header has a **Follow my writing** switch, replacing the wrapping
  checkbox, with "Related to: _first words…_".
- AC-2 While following: **Your notes (n)** (marks and source notes) and **From your papers
  (n)** (chunks), each with source and page.
- AC-3 Queries fire when the cursor leaves a paragraph or after 600 ms idle, never per
  keystroke. Tested with fake timers and a spy.
- AC-4 Results already cited in the paragraph are marked "cited here" and sorted last.
- AC-5 Typing in search takes over; clearing it resumes following.

### M3-2 One-click cite with a pinpoint

Refs: UX-3, UX-5 · Depends on: M3-1, M1b-8

- AC-1 **Cite** on a note, highlight or passage inserts a citation with the page as the
  locator: the page label if set, else the sheet number.
- AC-2 A source not in the project is added to it, as today.

### M3-3 Nudge covers source notes

Refs: UX-5 · Depends on: M1b-8

- AC-1 Source notes count toward the nudge, which is still at most one ring per paragraph.
- AC-2 Existing NoteNudge tests pass, plus one for a source note.

### M3-4 Settings

- AC-1 Settings › Reading: **Follow my writing** (default on) and **Margin nudge** (default on),
  persisted.

### M3-5 States that say what happened

Refs: UX-5 · Depends on: M3-1

- AC-1 Four distinct messages: no notes on this project's sources yet; nothing close to this
  paragraph; the search failed (with the reason); no manuscript open.
- AC-2 A component test per state.

**M3 Verify:** typing latency in the harness (5,000-word document, scripted typing) with
following on vs off: p95 keystroke-to-paint difference under 8 ms, recorded; the panel never
takes focus.
