# M4 — Attribution check

Cut line agreed 2026-09-24: if M1b overruns its size by half, M4 moves to 1.1 by decision.

### M4-1 Fixtures and harness, first

Refs: TEST, ADR-6 · Depends on: M1b-8

- AC-1 A labelled set of ≥ 120 manuscript sentences over the retrieval corpus plus source
  notes. Categories: verbatim-uncited, verbatim-cited-unquoted, quoted-and-cited exact, drifted
  quote, wrong-source citation, self-reuse, stock phrase (in ≥ 10 sources), clean paraphrase,
  PDF-artefact text.
- AC-2 `eval_attribution` prints a confusion matrix per category, and `last-run` is
  committed.
- AC-3 No UI work (M4-5 onwards) starts until the harness exists.

### M4-2 Sentence walk

Depends on: M1a-8

- AC-1 A pure function from a ProseMirror doc to sentences with `from`/`to` positions,
  skipping citation nodes, the bibliography and endnotes.
- AC-2 Uses `splitSentences` rules (abbreviations, initials, decimals), with tests on
  headings, lists and tables.

### M4-3 Shingle matching

Refs: ADR-6 · Depends on: M4-2

- AC-1 Normalisation (NFKC, casefold, punctuation, ligatures, quotes, dashes, hyphenation)
  shared by both sides. Property: idempotent.
- AC-2 Manuscript 6-gram map; a single streamed pass over chunks, highlights, note quotes and
  project manuscripts; document frequency counted only for hits.
- AC-3 Hits collapse into spans with `verbatim_score`; overlapping chunks are deduplicated.
- AC-4 A 10k-word manuscript over 56k chunks runs in under 1 s on the dev machine, measured and
  recorded.

### M4-4 Classification

Refs: ADR-6 · Depends on: M4-3, M1b-3

- AC-1 Each span is classified as: no citation nearby, drifted quote, wrong-source citation, or
  self-reuse, using canonical ids and quote detection.
- AC-2 Thresholds are chosen from the harness, and the chosen precision per category is
  recorded in the PR.
- AC-3 Stryker mutation score ≥ 85% on the classifier module.

### M4-5 Check panel

Refs: UX-7 · Depends on: M4-4

- AC-1 A new rail item, **Check**, between Notes and Sources, opens the UX-7 panel.
- AC-2 A scope line with counts; never a percentage; never "no problems found" (the empty
  message is fixed copy).
- AC-3 Findings are grouped by kind, titled in words.
- AC-4 Selecting a finding underlines only that sentence and opens the source in the split at
  the page with the passage marked (`showInPdf`).
- AC-5 Stale state after edits: a banner plus dimmed findings.
- AC-6 It never runs unasked, and never on open.

### M4-6 Fixes

Refs: UX-7 · Depends on: M4-5

- AC-1 **Quote and cite** (with pinpoint), **Cite**, **Make a block quote**, **Use the source's
  words** (drifted quote), **Show source**, **Dismiss**, each offered only where it fits.
- AC-2 After a fix, that finding re-checks immediately and clears.

### M4-7 Dismissals persist

Refs: UX-7 · Depends on: M4-5

- AC-1 Project migration 2 adds `dismissed_findings(normalised_sentence_hash, canonical_id,
kind, dismissed_at)`, tested against a real v1 project DB.
- AC-2 A dismissal survives restart and cosmetic edits (whitespace, punctuation). Changing the
  words brings the finding back.
- AC-3 The **Dismissed (n)** group can restore a dismissal.

### M4-8 Copy review

- AC-1 Every string in the panel is checked against docs/ux.md Principles 2–3. No "plagiarism",
  "violation", "score" or "%".
- AC-2 A test fails on those words in the panel's string module.
